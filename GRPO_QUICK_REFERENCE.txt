3️⃣  transfuser_loss.py - compute_grpo_loss3()
   ✓ 组内优势: advantages = (rewards - mean) / std
   ✓ Log ratio: log(π_θ) - log(π_ref)
   ✓ GRPO loss: -mean(log_ratios * advantages)
   
   mean_r = rewards.mean(dim=1, keepdim=True)
   std_r = rewards.std(dim=1, keepdim=True)
   advantages = (rewards - mean_r) / (std_r + 1e-8)
   
   current_probs = F.softmax(current_poses_cls, dim=-1)
   ref_probs = F.softmax(ref_poses_cls, dim=-1)
   log_ratios = torch.log(current_probs) - torch.log(ref_probs)
   
   grpo_loss = -torch.mean(log_ratios * advantages)

🔑 关键概念
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Trainable Params    : 只有 diff_decoder (DiT block)
Ref Policy          : 预训练 diff_decoder 的冻结拷贝
Rewards             : PDM score (progress + TTC + comfort)
Advantage           : 组内归一化 (rewards - mean) / std
Log Ratio           : log π_current - log π_ref
GRPO Loss           : -E[log_ratio × advantage]
KL Regularization   : KL(π_current || π_ref)

Q: rewards = None
A: 检查 tokens_list 传递，metric_cache 路径

Q: GRPO loss = NaN
A: 检查 PDM rewards 有效性，使用 compute_grpo_loss3

Q: OOM (内存不足)
A: 减少 batch_size，检查 torch.no_grad() 使用

Q: Validation 报错
A: 确保 forward_test 返回 final_poses_cls (即使 rewards=None)
